# Generic Trap Cards

Definition: trap cards from the field that interfere with the opponent. Excludes counter traps and cards whose primary function is self-benefit like recursion or search.

- **Board Wipe Traps**

- 激流葬 53582587, when a monster is Normal or Special Summoned destroy all monsters on field, universal clear, triggers on own summon too, useless against non-summon decks, typical count 0-1
- 神聖なるバリア ミラーフォース 44095762, when opponent declares an attack destroy all attack position opponent monsters, battle defense only, does not stop effect damage, typical count 0-1
- 奈落の落とし穴 29401950, when opponent summons a monster with 1500 or more ATK destroy that monster and banish it, anti-high ATK, useless against low ATK decks, typical count 0-1
- 強制脱出装置 94192409, return 1 monster on field to hand, universal bounce, opponent can re-summon, typical count 0-1
- 颉颃勝負 15693423, if opponent controls more cards banish face-down until equal, can activate from hand if your field is empty, late game clear, needs empty field for hand activation, typical count 0-1

- **Continuous Lockdown Traps**

- スキルドレイン 82732705 lim1, pay 1000 life points negate all face-up monster effects on field while this card is face-up on field, universal negate, limited to 1, does not negate already applied effects, recovers if removed, typical count 0-1
- 虚无空间 5851097 lim0, neither player can special summon, lockdown forbidden by ban list, limited to 0 copies, destroys itself if it leaves field, affects you too, typical count 0
- 魔封の芳香 58921041 lim1, all Spell cards must be Set for 1 turn before they can be activated, anti-quick-play, limited to 1, affects your own spells too, typical count 0-1
- 御前試合 53334471 lim1, each player can only control face-up monsters of 1 attribute, anti-mixed attribute, limited to 1, single attribute decks immune, typical count 0-1
- 千差万別 24207889 lim1, each player can only control 1 monster of each type, anti-mixed type, limited to 1, single type decks immune, typical count 0-1
- 群雄割拠 90846359 lim1, each player can only control 1 monster of each type, same as 千差万別 but different card, limited to 1, typical count 0-1
- 次元障壁 83326048 lim1, declare 1 type neither player can special summon monsters of that type and negate effects of that type, anti-specific summon method, limited to 1, affects you too, typical count 0-1
- 大宇宙 30241314, cards that would be sent to graveyard are banished instead, anti-graveyard, affects your own plays too, conflicts with mill strategies, typical count 0-1
- 王宮の鉄檻 23516703, monsters special summoned by opponent have effects negated and are destroyed during End Phase, anti-special summon, useless against normal summon decks, typical count 0-1
