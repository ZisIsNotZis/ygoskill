# Tool Scripts

## Deck Tools
- **[ydkshow.py](ydkshow.py)** — Card lookup and deck consensus analysis
- **[ydkcheck.py](ydkcheck.py)** — Deck validation and quality scoring

## Database Tools
- **[raceattrstat.md](raceattrstat.md)** — Attribute and race distribution statistics
- **[cardssql.md](cardssql.md)** — Human-readable SQL format for DIY card data
- **[cdb2sql.md](cdb2sql.md)** — CDB to SQL converter with human-readable format

## Dataset Tools
- **[deckarchive.md](deckarchive.md)** — Tournament deck archive research dataset

## Image Tools
- **[ypicdown.md](ypicdown.md)** — Download missing card images from CDN
- **[ypicgen.md](ypicgen.md)** — Generate card images from database and artwork

- **[autokey.md](autokey.md)** — AutoKey scripts for WeChat Mini Program deck crawler to clipboard
- **[clipdown.md](clipdown.md)** — Clipboard monitor for auto-saving clipboard content when updated
