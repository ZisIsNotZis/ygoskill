- **Effect Types**

- EFFECT_TYPE_SINGLE = 0x0001 (self-only trigger) / EFFECT_TYPE_FIELD = 0x0002 (field-wide trigger) / EFFECT_TYPE_EQUIP = 0x0004
- EFFECT_TYPE_ACTIVATE = 0x0010 (spell/trap activation) / EFFECT_TYPE_FLIP = 0x0020 / EFFECT_TYPE_IGNITION = 0x0040
- EFFECT_TYPE_TRIGGER_O = 0x0080 (optional trigger) / EFFECT_TYPE_QUICK_O = 0x0100 (optional quick effect)
- EFFECT_TYPE_TRIGGER_F = 0x0200 (mandatory trigger) / EFFECT_TYPE_QUICK_F = 0x0400 (mandatory quick effect)
- EFFECT_TYPE_CONTINUOUS = 0x0800 / EFFECT_TYPE_XMATERIAL = 0x1000 / EFFECT_TYPE_GRANT = 0x2000 / EFFECT_TYPE_TARGET = 0x4000

- **Common Effect Type Combinations**

- EFFECT_TYPE_SINGLE + EFFECT_TYPE_CONTINUOUS — self-only continuous
- EFFECT_TYPE_FIELD + EFFECT_TYPE_CONTINUOUS — field continuous
- EFFECT_TYPE_SINGLE + EFFECT_TYPE_TRIGGER_O — self trigger optional
- EFFECT_TYPE_FIELD + EFFECT_TYPE_TRIGGER_O — field trigger optional
- EFFECT_TYPE_QUICK_O — optional quick effect / EFFECT_TYPE_QUICK_F — mandatory quick effect
- EFFECT_TYPE_FIELD + EFFECT_TYPE_TRIGGER_O with e:SetCode(EVENT_PHASE_START + PHASE_STANDBY) — standby phase trigger
